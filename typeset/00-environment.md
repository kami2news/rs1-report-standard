# 環境差をなくす規定 / Cross-platform rules

Windows・Mac・スマートフォン・提出先の PC のどれで開いても同じに見え、文字化けしないように、OS ごとに違いが出る部分を 1 つに絞って決める。LaTeX・Word・PDF・HTML のすべてに当てる。ここに書いた選択肢以外は使わない。ただし授業や提出先が書体・ファイル名・形式を指定したときは、その指定が優先する（README「授業の指定との関係」）。

## 1　書体：1 系統だけ

| 用途 | 書体 | 太さ | 入手 |
| --- | --- | --- | --- |
| 本文・見出し・図表（和文・欧文とも） | Noto Sans JP | 400 と 700 だけ | Google Fonts（無料・OFL） |
| LaTeX の本文・見出し | 原ノ味角ゴシック（HaranoAjiGothic） | Regular と Bold | TeX Live に同梱（入れる作業は不要） |
| コード | Noto Sans Mono | 400 だけ | Google Fonts |

- Noto Sans JP と原ノ味角ゴシックは、どちらも源ノ角ゴシック（Source Han Sans）をもとにした同じデザインなので、LaTeX と Word で見た目がそろう。
- 游ゴシック（Windows）・ヒラギノ（Mac）・メイリオなど、OS に付いてくる書体は使わない。字幅と行の高さが OS ごとに違い、改行と改ページがずれる原因になる。
- 代わりの書体（フォールバック）は指定しない。Noto Sans JP が入っていない PC には、PDF で渡す。
- 太さは 400 と 700 の 2 つだけ。500・600 や「太字ボタンで作る疑似太字」は、環境によって出方が変わるので使わない。
- 日本語に斜体をかけない。斜体は欧文の変数（式の $x$）と学名だけ。
- 数式の記号は、LaTeX では Latin Modern Math、Word では Cambria Math（両 OS の Word に付属）。数式の書体は 1 つの文書の中で混ぜない。

## 2　文字

文字コードは UTF-8 だけを使う。次の文字は OS や文字コードの変換で別の文字に化けたり、表示が変わったりするので使わない。

| 使わない | 理由 | 代わりに |
| --- | --- | --- |
| 〜（波ダッシュ）と ～（全角チルダ） | Mac と Windows で別の文字として扱われ、化ける | 数値の範囲は「10–20」（半角の en ダッシュ）、文では「から」 |
| ①②③、⑴⑵ | 機種依存文字 | (1) (2) (3) |
| ⅠⅡⅢ（ローマ数字の 1 文字） | 機種依存文字 | 半角英字の I II III |
| ㎜ ㎏ ㎡ などの単位記号 1 文字 | 機種依存文字 | mm kg m² を半角で（℃ は使ってよい） |
| ㈱ ㍉ № ℡ などの組文字 | 機種依存文字 | 株式会社、ミリ、No. |
| 半角カナ（ｶﾅ） | 化けやすい | 全角カナ |
| 全角の英数字（ＡＢＣ１２３） | 検索・並べ替えが狂う | 半角の英数字 |
| 絵文字 | PDF・印刷で消える | 語で書く |
| 外字・独自に作った字 | 他の PC に無い | 使わない |

- マイナスは、数式の中では LaTeX の `$-$`、Word の数式エディタのマイナスを使う。本文で数値の負号を書くときも数式として書く。ハイフン「-」や長音「ー」で代用しない。
- 数値と単位の間は半角スペース 1 つ。全角スペースは見出し番号の後ろだけに使う。

## 3　ファイル名とフォルダ

- 使ってよい文字は、半角の英小文字・数字・ハイフン（-）・アンダースコア（_）・ピリオド（.）だけ。日本語・空白・記号は使わない。
- 理由：Mac は濁点・半濁点を「文字＋濁点」の 2 文字に分けて保存するため、Mac で付けた日本語のファイル名は、Windows に送ると濁点が分かれたり化けたりする。zip にしたときも同じ。
- 長さは 64 文字以内、拡張子は小文字（`.pdf` `.docx` `.tex` `.png`）。
- 形式：`学籍番号_姓のローマ字_課題名のローマ字_YYYYMMDD.pdf`（例：`24xx000_yamada_water-quality_20261116.pdf`）。
- 提出先が日本語のファイル名を指定したときだけ、それに従う。そのときは提出に使う PC の上で名前を付ける。
- zip で渡すときは、Mac が自動で入れる `__MACOSX` と `.DS_Store` を含めない。

## 4　テキストファイルの文字コードと改行

| 種類 | 文字コード | 改行 |
| --- | --- | --- |
| `.tex` `.bib` `.md` `.py` `.r` `.txt` | UTF-8（BOM なし） | LF |
| `.csv`（Excel で開く） | UTF-8（BOM 付き） | LF |

- Shift_JIS（CP932）で保存しない。エディタの既定がそうなっていたら UTF-8 に変える。
- 区切り文字は半角カンマ、小数点は半角ピリオド。桁区切りのカンマは付けない。

## 5　画像

| 中身 | 形式 |
| --- | --- |
| グラフ・図・模式図 | SVG か PDF（ベクター）。Word に入れるときは SVG |
| 写真 | JPEG（品質 80 以上）、300 dpi 以上 |
| 画面のスクリーンショット | PNG |

- HEIC（iPhone で撮った写真の既定の形式）は使わない。Windows や Word で開けないことがある。iPhone の「カメラ」設定で「互換性優先」にするか、JPEG に書き出す。
- EMF・WMF（Windows 専用の形式）、WebP は使わない。
- 色は sRGB。CMYK で保存しない。

## 6　寸法・単位・日付

- 紙は、どのソフトでも A4 縦を自分で指定する（ソフトや地域の既定が Letter のことがある）。
- 長さの単位は mm と pt だけ。px は画面の部品（HTML）の中だけで使う。換算は 1 pt = 1/72 in、1 mm = 2.835 pt。
- Word の行送りは「固定値」にする。「1 行」「倍数」は書体と OS で高さが変わる。
- 日付は、ファイル名では `YYYYMMDD`、本文では「2026年11月16日」、表の中では `2026-11-16`。

## 7　ソフトの版

| ソフト | 版 |
| --- | --- |
| LaTeX | TeX Live 2023 以降（Mac の MacTeX も中身は同じ TeX Live） |
| Word | Microsoft 365 の Word（Windows・Mac）。形式は `.docx` だけで、互換モード（`.doc`）は使わない |
| PDF の確認 | Adobe Acrobat Reader。Mac の「プレビュー」で開いた PDF を保存し直さない（埋め込み情報が変わることがある） |
| 表計算 | Excel か Google スプレッドシート。グラフを渡すときは画像（SVG・PNG）にする |

## 8　提出前のチェック

- [ ] ファイル名が半角英数字・ハイフン・アンダースコアだけ
- [ ] PDF の書体が Noto Sans JP（または原ノ味角ゴシック）と数式の書体だけで、すべて埋め込まれている
- [ ] 〜 ① Ⅰ ㎜ 半角カナ 全角英数字が残っていない（検索して確かめる）
- [ ] 画像に HEIC・EMF・WebP が入っていない
- [ ] 用紙が A4、Word の行送りが固定値
- [ ] 別の OS（または別の PC）で PDF を開き、改行と頁番号がそろっている
