# 出力規定：PDF / PDF

RS1 の文書を PDF で提出・保存・共有するときの規定。LaTeX からも Word からも、最後はこの規定で確かめる。提出先が形式（ファイル名・容量・版）を指定しているときは、そちらを優先する。

## 1　形式

| 項目 | 規定 |
| --- | --- |
| 版 | PDF/A-2b を基本にする（長く保存でき、書体がすべて埋め込まれる）。PDF/A で出せないときは PDF 1.7 |
| 用紙 | A4 縦。横向きの頁は、大きな表・図だけに使う |
| 色 | ライトテーマ（白地）。カラーで作り、白黒で印刷しても読めること |
| 書体 | Noto Sans JP（LaTeX は原ノ味角ゴシック）・Noto Sans Mono・数式の書体だけ。すべて埋め込み（サブセット可） |
| 画像 | 図はベクター（線や文字が拡大してもにじまない）。写真は 300 dpi 以上、JPEG 品質 80 以上 |
| 容量 | 10 MB 以内（指定があれば従う）。超えるときは写真の解像度を 300 dpi まで下げる |
| 保護 | パスワード・印刷禁止・コピー禁止をかけない |

## 2　文書情報とナビゲーション

- 文書プロパティに、タイトル（表題）・作成者（氏名）・サブジェクト（種別）を入れる。
- 表示タイトルを「ファイル名」ではなく「文書のタイトル」にする（LaTeX は `pdfdisplaydoctitle=true`）。
- しおり（ブックマーク）を章・節の見出しから作る。
- 目次・相互参照・`[n]` の引用はリンクにしてよい。リンクは文字色のまま（色・下線・枠線を付けない）。
- 言語を日本語（ja-JP）に設定し、可能ならタグ付き PDF（読み上げソフトが構造を読める）にする。

## 3　ファイル名

`学籍番号_姓のローマ字_課題名のローマ字_YYYYMMDD.pdf` を基本にする（例：`24xx000_yamada_water-quality_20261116.pdf`）。半角の英小文字・数字・ハイフン・アンダースコアだけを使い、日本語・空白・「final」「修正版」などの語は使わない（`00-environment.md`）。版を重ねるときは日付を変える。提出先が形式を指定していればそれに従う。

## 4　出力の手順

| 元のファイル | 手順 |
| --- | --- |
| LaTeX | `\DocumentMetadata{pdfstandard=a-2b, lang=ja-JP}` を 1 行目に置いてコンパイル（`typeset/10-latex.md`） |
| Word | 「名前を付けて保存」→ PDF →「オプション」で PDF/A・ブックマーク・構造タグに印（`typeset/11-docx.md`） |
| ブラウザ（HTML の部品） | 印刷 →「PDF に保存」、用紙 A4・余白「なし」（余白は `@page` の 25 mm が効く）・背景のグラフィックを有効 |

## 5　提出前のチェック

- [ ] 頁数・頁番号・用紙サイズ（A4）が正しい
- [ ] 書体がすべて埋め込まれている（Acrobat の「文書のプロパティ」→「フォント」、または `pdffonts` で全行が `emb yes`）
- [ ] 図がにじまない（400% に拡大して確かめる）
- [ ] 白黒で印刷プレビューして、図の系列と注記枠の種類が見分けられる
- [ ] しおりが章・節の順に並んでいる
- [ ] 文書プロパティのタイトルと作成者が正しい（テンプレートの値が残っていない）
- [ ] 変更履歴・コメント・隠しテキストが残っていない
- [ ] ファイル名が規定どおりで、容量が上限以内
- [ ] PDF/A で出したときは、検証ツール（veraPDF や Acrobat のプリフライト）で確かめた
