図と表を、番号付きのキャプションとともに置く部品で、図の説明は下、表の説明は上、表は縦罫のない三線表にする。

**使う側が用意するもの：** 図（SVG・画像）または表のデータ、キャプションの文（番号は自動）、表の出典・注（任意）、図の代替文（`aria-label`）。

- キャプションだけで、何を・どこで・いつ・単位が分かるように書く。キャプションは `t-caption`、色は `ink-muted`、番号「図 1」「表 1」は `ink` の太字。
- 表は上下に `ink` 2px、見出し行の下に 1px。縦罫は使わない。数値の列は右揃えで、単位は列見出しに入れる。
- 図に外枠を付けない（軸があれば十分）。図の中の文字は `t-note` 以上の大きさで。
- 系列は `chart-1`〜`chart-4` の順に使い、色・マーカー・線種を必ず組にする（`rp-s1`〜`rp-s4` と `rp-line` のクラス）。

| 系列 | 色 | マーカー | 線種 |
| --- | --- | --- | --- |
| 1 | `chart-1` | ● | 実線 |
| 2 | `chart-2` | ■ | 破線 |
| 3 | `chart-3` | ▲ | 点線 |
| 4 | `chart-4` | ◆ | 一点鎖線（参照線・理論値にも使う） |

- 系列が 5 つ以上なら、図を分けるか表にする。棒グラフは値を棒の上に直書きする。
- 白黒印刷でも系列が区別できるかを、提出前にグレースケールで確かめる。
- 本文で必ず「図 1 に示す」のように引く。引かれない図表は削る。
- 他者の図を転載するときは、出典と許可の有無をキャプションに書く。基本は描き直す。
- 値はダミー・暫定のときは、キャプションにその旨を書く。
