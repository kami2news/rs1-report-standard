卒業研究・論文（パターン F）の表紙で、年度と種別・題目・英題・所属・学籍番号・氏名・指導教員・提出日を、中央ぞろえで 1 頁に置く。

**使う側が用意するもの：** 年度、題目（和・英）、所属（学部・学科・研究室）、学籍番号、氏名、指導教員名、提出日。

- 学科・研究室の表紙様式があれば、そちらを使う。この部品は様式がないときの標準。
- 題目は `t-title`。2 行までに収め、改行は意味の切れ目で入れる。英題は `ink-muted`。
- 表紙には頁番号・ランニングヘッダーを付けない。`ReportPage` の枠だけを使う。
- 授業のレポート（A〜E、G）には使わない。1 頁目の頭に `TitleBlock` を置く。
- ロゴや装飾を入れない。色は `ink` と `ink-muted` だけ。
