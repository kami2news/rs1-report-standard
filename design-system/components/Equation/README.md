独立した式を、中央に置き、右端に式番号（1）（2）…を自動で付ける部品で、直後に記号の説明（ここで、…）を続ける。

**使う側が用意するもの：** 式、式に出るすべての記号の名前・単位。

- 変数は斜体、単位と数字は立体、添字は `sub` で。式はテキストで組めるものはテキストにして、画像にしない。
- 式番号は文書を通した連番で、本文では「式 (1)」と引く。引かれない式には番号を付けない。
- 記号の説明は式のすぐ下に `t-caption` で。単位をそろえて書く（例：濃度 (mg/L)）。
- 本文中に収まる短い式（`E = mc²` 程度）は、独立させずに文中に置く。
- 長い導出は付録に回し、本文には結果の式だけを置く。
- 式の中でコードと同じ名前を使うなら、その対応を `t-code` で示す。
