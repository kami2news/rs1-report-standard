A4 縦のページ枠で、上下左右の余白は `page-margin`、ランニングヘッダー（文書名と種別）とフッター（頁番号）を付ける。

**使う側が用意するもの：** 文書名、種別の名前、頁番号。本文はこの枠の中に `TitleBlock` から順に置く。

- 画面で見るときだけ、ページ外の台（`surface-subtle`）と `page-shadow` を使う。印刷・PDF では台と影を外し、`surface` の用紙だけにする。
- ヘッダーとフッターは `t-note`、色は `ink-muted`。ヘッダーの下線は装飾なので `line`。
- 表紙（卒業研究）ではヘッダーとフッターを出さない。
- 頁番号は「- 1 -」の形。目次のある文書では、表紙・目次をローマ数字にしてよい（学科の様式に従う）。
- 章をまたぐ図表は、頁の終わりで切らない。入らなければ次頁に送る。
