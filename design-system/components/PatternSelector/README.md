報告の種類（A〜H）を切り替えて、章立て・必須か任意か・書くことの要点を一覧する部品で、パターンを選ぶ前の確認や、章を借りる判断に使う。

**使う側が用意するもの：** なし。データは `patterns/` の各ページと同じ内容を持つ。章立てを変えたときは、各パターンのページと、この部品のプレビューを両方更新する。

- タブは「種類」の切り替えで、選択中は `ink` で塗り、`surface` の文字にする（文書と同じく黒と灰色だけ）。選択状態は塗りだけでなく `aria-selected` でも示す。
- 必須は塗りの枠、任意は破線の枠と「任意」の語で区別する。色には頼らない。
- ボタンの高さは PC で 32px、タッチ操作（`pointer: coarse`）で 44px。
- 左右の矢印キーでタブを移動できる。フォーカスは 2px の `focus-ring`（`ink`）。
- 実際の文書を作るときは、ここで章立てを確かめ、`patterns/` の骨子（コピー用）を使う。
