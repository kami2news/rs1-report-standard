章・節の見出しと頁番号を、点線のリーダーでつないで一覧する目次で、卒業研究・論文（F）では必須、フィールド・観測（C）では任意。

**使う側が用意するもの：** 見出しの語と番号、頁番号。PDF ではリンク先（見出しの id）。

- 載せるのは章（`lv1`、`t-body`）と節（`lv2`、`t-caption`）まで。項（`lv3`）は 30 頁を超える文書だけ。
- 番号と見出しは本文と完全に一致させる。最後に本文を直したら、目次も作り直す。
- 頁番号は右揃え、数字は等幅（`tabular-nums`）。
- 目次・謝辞・参考文献・付録は番号なしで載せる。
- 図目次・表目次が必要なときは、同じ部品で別の一覧を作る。
- Word や LaTeX の自動目次を使えるときはそれを使い、この部品の見た目に合わせる。
