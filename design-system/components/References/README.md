参考文献を、本文に出てくる順の番号 [1] [2] … でぶら下げ字下げに並べる部品。

**使う側が用意するもの：** 引用した文献の書誌情報（著者・年・題名・誌名・巻（号）・頁・DOI）。

- 本文では `[1]` や `[2, 3]`、連続は `[4–6]` と書く。番号は出てくる順で、後から入れ替えたら全部振り直す。
- 書式は種類ごとに次のとおり（LaTeX の `rs1.sty` は自動でこの形に出す）。

| 種類 | 書式 |
| --- | --- |
| 論文 | 著者（年）題名．誌名，巻（号），頁（または論文番号）．doi:… |
| 書籍 | 著者（年）書名（第 n 版）．出版社，出版地． |
| 本の章 | 著者（年）章の題名．編者（編）書名，頁．出版社，出版地． |
| Web・データ | 著者または機関（年）名称（版）．URL（最終閲覧日：YYYY年M月D日） |

- 和文の著者は「姓 名」、著者の区切りは「・」。欧文の著者は「Family, G.」、区切りは「, 」。論文・書籍・章・データの 4 型を、混ぜずに同じ順で書く。
- 著者の数：5 名までは全員を書く。6 名以上は最初の 3 名を書き、和文は「ほか」、欧文は「et al.」を続ける（例：Yamada, T., Suzuki, K., Smith, J., et al.）。授業・提出先が「全員」などと指定したら従う。
- 本文で著者名を出すとき：1 名は「田中 [1]」、2 名は「田中・鈴木 [2]」、3 名以上は「田中ほか [3]」「Smith et al. [3]」。
- 頁が無く論文番号（article number）だけの電子ジャーナルは、頁の位置に論文番号を書く（例：12（3），e0123456）。号が分からないときは号を省いて「巻，論文番号」。巻・号がまだ付いていない早期公開の論文は「（早期公開）」と書き、DOI を必ず書く。
- 図を転載した文献も、一覧には文献そのものだけを書く。ライセンス名や「転載」は書かない（図のキャプションに書く。`FigureTable` を参照）。
- 一覧は `t-caption`。番号は左に出し、2 行目以降は番号の右にそろえる。
- 本文に引いていない文献は載せない。引いたのに載っていない文献もないようにする。
- データ・ソフトウェアも、名称・版・提供者・取得日で書く。URL だけにしない。
- 所属する学科・学会が著者年方式を指定するときは、その様式に従う。部品の枠だけ使い、番号を外す。
- 書誌を確認できなかった文献は載せない。原典を見られず孫引きするときは、その旨を書く。
