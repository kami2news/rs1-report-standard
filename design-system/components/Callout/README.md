本文の流れを止めてよい補足を、行頭のラベル（［注記］［前提］［注意］［未解決］）と 1 字下げで示す部品。枠・背景・色は使わない。

**使う側が用意するもの：** 種類（4 種のどれか）と、1〜3 文の本文。

| 種類 | 使うとき |
| --- | --- |
| 注記 | 読み飛ばしてもよい補足、値の出し方 |
| 前提 | 結果と考察が成り立つための仮定 |
| 注意 | 条件の例外、データの癖、解釈を狭める事情 |
| 未解決 | まだ説明できないこと、相談したい点 |

- 書き方は `<p class="rp-callout t-body"><span class="rp-callout-label">注記</span>　本文</p>`。ラベルは太字、角括弧は自動で付く。
- 種類はラベルの語だけで区別する。色や線を足さない。
- 1 頁に 2 つまで。多いときは本文に書き直す。
- 注意と未解決は、提出前に本文へ取り込めないか確かめる。ゼミのレジュメでは「未解決」を相談事項として残してよい。
- 中に図表や箇条書きを入れない。
