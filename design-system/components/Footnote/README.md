本文の流れを止めたくない補足を、本文に上付きの番号、頁の下に注として置く部品。

**使う側が用意するもの：** 注を付ける語の位置と、注の本文（1〜2 文）。

- 番号は句読点の直前に付ける（「…行った¹。」）。番号は文書を通して連番。
- 注の欄は頁の下、本文との間に短い区切り線（`line-strong`、幅 40%）を置く。文字は `t-note`、`ink-muted`。
- 注は補足だけに使う。文献の出典は注にせず `References` の `[n]` で示す（学科が脚注方式を指定するときは除く）。
- 結果や考察の主張を注に逃がさない。読まれなくても論旨が通るものだけを注にする。
- 1 頁に注が 3 つを超えたら、本文に書き直すか `Callout` の「注記」を使う。
