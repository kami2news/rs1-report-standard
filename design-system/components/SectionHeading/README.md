章・節・項の見出しで、番号（1 / 1.1 / 1.1.1）を CSS のカウンタで自動に付ける。

**使う側が用意するもの：** 見出しの語。章は `h2.rp-h1.t-h1`、節は `h3.rp-h2.t-h2`、項は `h4.rp-h3.t-h3`（文書の `h1` は表題が使う）。

- 階層は 3 つまで。4 階層目が必要なら、章の分け方を見直す。
- 見出しに下線・色・記号を付けない。大きさと太さだけで階層を示す。
- 参考文献・付録・謝辞には `rp-unnumbered` を付けて番号を消す。番号は章の連番を止めない。
- 見出しは名詞で終える（「目的」「試料と方法」）。文にしない。
- 1 つの章の下に節を 1 つだけ置かない。節を作るなら 2 つ以上。
- 見出しの直後に、見出しだけが頁の末尾に残らないようにする。
