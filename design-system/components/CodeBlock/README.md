付録や方法に載せるコード・コマンドを、等幅書体（`t-code`）で、上下の細い線（`line-strong`）の間に番号付きの説明とともに置く部品。背景色や囲みは付けない。

**使う側が用意するもの：** コード本文、説明（言語と版、主なライブラリの版）、本文からの参照。

- 説明は上に「コード 1」の形で置き、言語とライブラリの版を書く（データ解析 D の再現情報になる）。
- 本文には結果に必要な部分だけを載せ、全体は付録か、リポジトリの所在で示す。
- 1 枠は 1 頁に収まる長さ（40 行程度）まで。長いものは付録に回す。
- 文中のファイル名・変数名・コマンドは `t-code` でインラインに書く。
- 色付けは使わない（印刷で消えるため）。必要なら `ink-muted` のコメントだけ。
- パスワード・API キー・個人情報が入っていないかを、載せる前に確かめる。
