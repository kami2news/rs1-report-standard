要旨またはその短縮版の要約を、中央の見出し「要旨」と、左右を 2 字下げた本文で置くブロック。囲み・背景・色は使わない。

**使う場面：** 卒業論文（F）と中間報告（E の要約 3 行）、授業・学会で要旨を求められたときだけ。授業のレポート（A〜D、G）には付けない。

**使う側が用意するもの：** 要旨の本文（200〜800 字、パターンで異なる）、キーワード 3〜5 語。中間報告では 3 行の要約。

- 要旨は本文を書き終えてから最後に書く。序論の書き出しではない。
- 要旨は目的・方法・主な結果・結論の順に、本文を読まなくても分かるように書く。本文にない数値や主張を入れない。
- 引用（`[n]`）・図表番号・略語の説明を要旨の中に書かない。
- キーワードは読点（，）で区切り、「キーワード：」は太字にする。
- 中間報告の要約 3 行は、目的・現状・次の作業の順。
- 論文（F）の英文要旨は、和文要旨の直後に別ブロックとして置く。
- 文字はすべて `ink`。
