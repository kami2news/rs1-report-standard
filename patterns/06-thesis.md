# F　卒業研究・論文 / Thesis

研究全体を一本の文書にまとめる。他のパターンの章を「節」として取り込める、いちばん長い型。形式は所属する学科・研究室の様式を最優先し、このページは様式で決まっていない部分を補う。分量は 30 頁以上。

## 章立て

| 章 | 必須 | 書くこと | 目安 |
| --- | --- | --- | --- |
| 表紙・題目 | ● | 学科の様式に従う | 1 頁 |
| 要旨（和・英） | ● | 全章を書き終えてから書く。「何が問題だったか」「何をしたか」「どうやって解いたか」「何が分かったか」に答える形で。序論の書き出しにしない。和文 600〜800 字、英文は同内容 | 各 1 頁 |
| 目次 | ● | 章・節・項と頁 | 1 頁 |
| 1　序論 | ● | 1.1 背景、1.2 先行研究（B の整理を取り込む）、1.3 目的と問い、1.4 本論文の構成 | 3〜6 頁 |
| 2　調査地域・対象 | ● | C の「調査地域」に相当。実験・解析のみなら「研究対象」 | 2〜4 頁 |
| 3　試料・データ・方法 | ● | A の方法、C の観測・分析、D のデータと手法を、必要な分だけ節にする | 4〜8 頁 |
| 4　結果 | ● | 節ごとに 1 つの問いに答える。事実だけ | 6〜12 頁 |
| 5　考察 | ● | 節ごとに結果と対応させ、全体の議論を最後の節で | 4〜8 頁 |
| 6　結論 | ● | 問いへの答え、成果、今後の課題 | 1〜2 頁 |
| 謝辞 | ● | 指導教員・協力者・機関 | 0.5 頁 |
| 参考文献 | ● | 全引用 | |
| 付録 | ○ | 生データ、コード、野帳 | |

## 独自性

先行研究をつなぎ合わせて要約しただけでは論文にならない。自分のデータ、または複数の先行研究を照らし合わせた自分の判断が、どこにあるかを序論の最後と結論で明示する。

## 取り込みの規則

- 他のパターンの章を節に格下げするとき、番号と見出しの階層だけを変え、内容の書き方（必須項目・図表の標準）は元のパターンに従う。
- 序論の問いと、結論の答えが 1 対 1 で対応しているかを最後に確認する。
- 図表の番号は章をまたいで通し番号（図 1, 図 2 …）。章ごとにふる（図 3.1 など）かは、研究室の様式に合わせる。

## 使う部品

全部品。`ReportPage` は、章扉の頁を除いて本文に使い、ランニングヘッダーに章題を入れる。`SectionHeading` は 3 階層、`References` は番号方式のまま（様式が著者年方式なら様式に従う）。

## チェックリスト

- [ ] 学科・研究室の様式に反していない
- [ ] 序論の問い、結論の答えが対応している
- [ ] 要旨の数値が本文の数値と一致している
- [ ] 図表・式・参考文献の番号が本文と合っている
- [ ] 謝辞に、指導・協力・資金・機材の提供が漏れなく書かれている
- [ ] 目次の頁番号が最終版の頁番号と一致している
