# C　フィールド・観測レポート / Field and observation report

現地での観測・採取・調査を報告する。条件が現地の事情で変わるので、「どこで・いつ・どう測ったか」の記録が中心になる。例：湖沼の水質観測、巡検での地層観察、気象観測のケーススタディ。分量は巡検・実習のレポートなら A4 4〜10 枚、研究としての観測報告なら 8〜20 頁。

## 章立て

| 章 | 必須 | 書くこと | 目安 |
| --- | --- | --- | --- |
| 要旨 | △ | 付けない。授業・提出先の指示があるときだけ、場所・期間・方法・主な結果・結論を 300 字以内で | 6〜8 行 |
| 1　はじめに | ● | 調査の背景と目的、先行研究の要点 | 0.5〜1.5 頁 |
| 2　調査地域 | ● | 位置図（緯度経度・縮尺・方位）、地形・地質・気候など必要な概況 | 1〜2 頁 |
| 3　方法 | ● | 3.1 観測・採取（期間・地点・機器・間隔）、3.2 分析・処理（前処理・欠測の扱い）、3.3 精度管理 | 1〜2 頁 |
| 4　結果 | ● | 地点ごと・時期ごとに事実だけ。写真・スケッチ・時系列図 | 2〜6 頁 |
| 5　考察 | ● | 現地条件（天候・季節・地形）との関係、地点間・時期間の差、観測の限界 | 1〜4 頁 |
| 6　結論 | ● | 目的への答えと、次に確かめたいこと | 0.5 頁 |
| 謝辞 | ○ | 調査への協力、許可、機材の提供 | 2〜3 行 |
| 参考文献 | ● | | |
| 付録 | ○ | 野帳の写し、全地点の座標、欠測一覧、QA/QC の記録 | |

## 使う部品

`TitleBlock`（表紙を付けないとき。条件の行に調査日・天候を書く）、`Abstract`（指示があるときだけ）、`SectionHeading`、`FigureTable`（位置図・写真・時系列）、`Callout`（「注意」で観測条件の例外、「前提」で仮定）、`References`。

## 図表の標準

- 位置図には、緯度経度または座標系、縮尺、方位、地点名を入れる。
- 写真には、撮影日・場所・向き（北向きなど）・縮尺になる物を示す。
- 時系列図の横軸は日時（時刻の基準を書く：JST など）、縦軸に単位。欠測は線を結ばず空ける。
- 地点を示す記号は色だけでなく、形（●■▲）でも区別する。

## 倫理・許可

- 立入・採取の許可を得た相手と日付を、方法に書く（調査地が私有地・保護区のとき）。
- 位置を公開すると採取地が荒れるおそれがあるときは、座標の精度を落とすか、付録で限定配布にする。

## チェックリスト

- [ ] 位置・日時・天候が分かる
- [ ] 機器の型番・設定、校正の有無が書かれている
- [ ] 欠測や例外の観測が、結果か付録に正直に示されている
- [ ] 結果と考察が分かれている
- [ ] 位置図・写真に縮尺と方位がある
- [ ] 許可と謝辞が必要な箇所に書かれている
