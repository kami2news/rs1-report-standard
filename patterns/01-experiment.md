# A　実験・実習レポート / Experiment report

測定や分析の実習・実験を、他の人が同じ手順でやり直せる形で報告する。例：河川水の主要イオン分析、岩石試料の蛍光 X 線分析、気象測器の比較観測。分量は表紙を除いて A4 4〜8 枚（生データの付録は別）。授業で枚数・様式（配布の Word ファイル、レポート用紙への手書き）が決まっているときは、そちらに従う。

## 章立て

| 章 | 必須 | 書くこと | 目安 |
| --- | --- | --- | --- |
| 要旨 | △ | 付けない。授業の指示があるときだけ、目的・方法・主な結果・結論を 200 字以内で | 4〜6 行 |
| 1　目的 | ● | 何を明らかにするか。1〜3 文。「〜を確かめる」「〜を求める」の形。実習書の丸写しでなく自分の言葉で | 3〜5 行 |
| 2　原理・背景 | ● | 測定原理、使う式、前提と仮定。教科書を要約して書く。式は `Equation` で番号を付ける | 0.5〜1 頁 |
| 3　試料・装置・方法 | ● | 3.1 試料、3.2 装置、3.3 手順に分ける。量・型番・メーカー・試薬の等級・濃度・温度・時間を書く。過去形で。実習書と違う手順になった場合は、実際にやった手順を書く | 1〜2 頁 |
| 4　結果 | ● | 測定値と図表だけ。推測・判断は書かない。結果の順は方法の順に合わせる | 1〜3 頁 |
| 5　考察 | ● | なぜその結果になったかを、原理と比べて論理的に述べる。一致したら「どこが・どの程度」、ずれたら「なぜ」。誤差の原因と方法の限界、課題文の問いへの答え。感想・反省は書かない | 1〜2 頁 |
| 6　課題 | △ | 実習書・授業の設問に答える章。設問ごとに番号を付けて答える。出題があれば必須 | 設問ごと |
| 7　結論 | ● | 目的への答えを文で。数値は結果と同じ有効数字。「まとめ」と呼ぶ授業もある | 3〜6 行 |
| 参考文献 | ● | 原理・文献値の出典 | |
| 付録 | ○ | 生データ、計算過程 | |

## 表紙

実験レポートは表紙を付けるのが一般的。表紙には次を書く（授業の様式があればそれに従う）。

| 項目 | 書き方 |
| --- | --- |
| 講義名・実験テーマ名 | テーマ番号があれば番号も |
| 実験日 | 曜日も書く（例：2026年10月14日（水）） |
| 提出日 | 振替実験などで遅れたときは、その旨も |
| 実験時の環境 | 天候・気温・湿度（気圧が結果に関わる実験では気圧も）。測定に影響しない実験では省いてよい |
| 学籍番号・氏名 | 自分のもの |
| 共同実験者 | 学籍番号と氏名をフルネームで |

## 手書きで出すとき

- ボールペンで書く（鉛筆・消えるボールペンは使わない）。
- グラフは方眼紙に描き、軸・単位・目盛り・凡例を手で書き入れる。
- 図表の番号・キャプション・章立ての決まりは、印刷するときと同じ。

## 使う部品

`CoverPage`（表紙。上の項目を並べる）または `TitleBlock`（表紙を付けない授業のとき）、`Abstract`（指示があるときだけ）、`SectionHeading`、`Equation`、`FigureTable`（結果は表を先に、図は傾向を見せるときに）、`Callout`（「前提」で仮定を明記）、`References`。

## 図表の標準

- 測定値の表は三線表。列見出しに単位を入れ、数値は右揃え。
- 測定の繰り返しがあるときは、平均 ± 標準偏差か、個別値のどちらかを選んで示す（`n` を書く）。
- 検量線は、標準試料の点・回帰直線・式・決定係数 R² を 1 つの図に収める。

## チェックリスト

- [ ] 表紙に実験日（曜日）・環境・共同実験者が書かれている
- [ ] 設問（課題）があれば、すべてに番号付きで答えている
- [ ] 目的と原理が、実習書の丸写しになっていない
- [ ] 方法が過去形で、実際にやった手順になっている
- [ ] 課題文の問い（「〜について述べよ」）に考察で答えている
- [ ] 考察が感想・反省で終わっていない
- [ ] 目的と結論が同じ言葉で対応している
- [ ] 他の人が手順を再現できる（試料・装置・条件・日時）
- [ ] 結果に解釈を書いていない
- [ ] 誤差の原因が、考察に最低 1 つ具体的に挙がっている
- [ ] すべての図表が本文で引かれ、単位が入っている
- [ ] 式に番号があり、記号の説明（where）が続いている
- [ ] 参考文献が本文の `[n]` と対応している
