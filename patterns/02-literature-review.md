# B　文献調査レポート / Literature review

自分では測定せず、既存の研究や資料を集めて整理・比較し、現時点で何が分かっていて何が分かっていないかを示す。例：大気中エアロゾルの衛星観測手法の比較、低周波地震の発生機構の研究動向。分量は授業の課題なら 2,000〜6,000 字（A4 2〜5 枚）、ゼミ・卒業研究の準備なら 6〜15 頁。

## 章立て

| 章 | 必須 | 書くこと | 目安 |
| --- | --- | --- | --- |
| 要旨 | △ | 付けない。授業・提出先の指示があるときだけ、問い・調べ方・分かったこと・残った課題を 300 字以内で | 6〜8 行 |
| 1　背景と問い | ● | なぜこの主題か、何を知りたいか。問いは 1〜3 個に絞って明示する | 0.5〜1 頁 |
| 2　調査方法 | ● | 検索した場所（データベース名）、キーワード、期間、選んだ基準・外した基準、採用した件数 | 0.5 頁 |
| 3　文献の整理 | ● | 年代・手法・対象地域・結論のどれかの軸で分類して述べる。1 文献を 1 段落で終わらせず、軸ごとにまとめる | 2〜6 頁 |
| 4　比較と考察 | ● | 文献どうしの一致・食い違い、食い違いの理由、方法の強み弱み。自分の評価はここに書き、3 章には混ぜない | 1〜3 頁 |
| 5　結論と今後の課題 | ● | 問いへの答えと、まだ分かっていないこと | 0.5〜1 頁 |
| 参考文献 | ● | 引いた文献すべて。調査対象とした全件は付録に | |
| 付録　文献一覧表 | ○ | 著者・年・対象・手法・主な結果の表 | |

## 使う部品

`TitleBlock`（表紙を付けないとき）、`Abstract`（指示があるときだけ）、`SectionHeading`、`FigureTable`（分類の比較表が中心。三線表、行に文献、列に軸）、`Callout`（「未解決」で研究間の食い違いを示す）、`References`。

## 図表の標準

- 比較表：行は文献（`[n]` で引く）、列は軸（手法・対象・期間・主な結果）。空欄は「―」ではなく「記載なし」。
- 年ごとの文献数など、動向を見せる図は棒グラフ。年と件数に単位を入れる。
- 他の論文の図は自分で描き直すのが基本。CC ライセンスの図を転載するときは、出典・変えた点・ライセンス名をキャプションに書く（`FigureTable` の説明）。

## チェックリスト

- [ ] 問いが背景に書かれ、結論がその問いに答えている
- [ ] 調べ方を読めば、第三者が検索をやり直せる
- [ ] 3 章は整理だけ、評価は 4 章に分かれている
- [ ] 一次文献を引いている（総説だけで済ませていない）
- [ ] 食い違う結論を、片方だけ選んで落としていない
- [ ] 引用はすべて自分の言葉で書き直し、出典を番号で付けている
