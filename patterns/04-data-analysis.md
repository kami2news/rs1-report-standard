# D　データ解析・シミュレーションレポート / Data analysis and simulation report

既存のデータを解析する、またはモデルを計算する報告。結果が計算で決まるので、手法・パラメータ・環境の記録がそのまま再現性になる。例：地震波形の解析、衛星画像からの植生指数の算出、大気化学の箱モデル。分量は授業の課題なら A4 4〜10 枚、研究としての解析なら 6〜15 頁。

## 章立て

| 章 | 必須 | 書くこと | 目安 |
| --- | --- | --- | --- |
| 要旨 | △ | 付けない。授業・提出先の指示があるときだけ、目的・データ・手法・主な結果・結論を 300 字以内で | 6〜8 行 |
| 1　はじめに | ● | 背景、何を解析して何を知りたいか、先行研究の要点 | 0.5〜1.5 頁 |
| 2　データ | ● | 出典（URL でなく名称・版・取得日）、期間・範囲・解像度、欠損、ライセンス | 0.5〜1 頁 |
| 3　手法・モデル | ● | 3.1 前処理、3.2 手法または支配方程式、3.3 パラメータと初期・境界条件。式は `Equation` | 1〜2 頁 |
| 4　結果 | ● | 図表中心。比較条件ごとに同じ軸・同じ範囲で並べる | 2〜5 頁 |
| 5　考察 | ● | 結果の意味、不確実性（誤差・感度・仮定の影響）、データと手法の限界 | 1〜3 頁 |
| 6　結論 | ● | 問いへの答え、次の解析 | 0.5 頁 |
| 参考文献 | ● | データ・手法・ソフトウェアの出典 | |
| 付録　再現情報 | ● | 環境（OS・言語・ライブラリの版）、乱数の種、実行手順、コードの所在 | 0.5〜1 頁 |

## 使う部品

`TitleBlock`（表紙を付けないとき）、`Abstract`（指示があるときだけ）、`SectionHeading`、`Equation`、`FigureTable`、`Callout`（「前提」でモデルの仮定、「注意」でデータの癖）、`References`、コードは `t-code`。

## 図表の標準

- 比較する図は、軸の範囲と単位を揃える。変える場合は、キャプションで断る。
- 時系列・分布・散布図は、凡例を図の中に置き、系列を色とマーカー（または線種）の両方で区別する。
- カラーマップは、順序のあるデータに連続的なもの、正負のあるデータに発散型を使う。虹色は避ける。
- 数値のまとめは、平均・標準偏差・最小・最大・件数をそろえた表で。

## チェックリスト

- [ ] データの出典・版・取得日が分かる
- [ ] パラメータの値と、その決め方（既往値か、調整か）が書かれている
- [ ] 結果が条件ごとに同じ条件で比較できる
- [ ] 不確実性への言及が考察にある
- [ ] 付録の再現情報で、他の人が同じ図を出せる
- [ ] 乱数を使う計算に、乱数の種が書かれている
