# G　論述レポート / Argumentative report

授業の課題（「〜について論じなさい」「賛成か反対か、理由とともに述べよ」）に対し、資料を根拠にして自分の主張を論じる。自分で測定はしない。文献調査（B）との違いは、整理で終わらず、問いへの自分の答えを主張する点。例：「再生可能エネルギーの導入拡大に賛成か」「気候変動への適応策として何を優先すべきか」。分量は 2,000〜4,000 字（課題の指定に従う）。表紙は付けず、1 頁目の頭に簡易ヘッダー（科目名・学籍番号・氏名）と表題を置く形が多い。指示があれば文末に総文字数を書く。

## 章立て（3 部構成）

| 章 | 必須 | 書くこと | 分量の配分 |
| --- | --- | --- | --- |
| 1　序論（はじめに） | ● | テーマの意義（なぜ今これを論じるか）、問い、自分の結論の予告、この先の章の順番 | 約 10% |
| 2　本論（章は 2〜3 個） | ● | 根拠を 1 章に 1 つずつ。各章は「主張 → 根拠（データ・文献）→ 根拠から主張を導く説明」 | 70〜80% |
| 　2.x　反論への応答 | ● | 自分と違う立場の意見と、その根拠を公平に紹介し、それでも自分の主張が成り立つ理由を述べる | 本論に含む |
| 3　結論（おわりに） | ● | 問いへの答えを繰り返し、論じた範囲と、論じきれなかったこと（限界・今後の課題） | 10〜20% |
| 参考文献 | ● | 本文で引いたものすべて | |

## 書き方の要点

- 問いは 1 つに絞る。「〜について」のような広いテーマのままにせず、「〜は〜か」と答えられる形にする。
- 主張は序論と結論で同じ言葉にする。結論で新しい主張を持ち出さない。
- 根拠は、出典の明らかな文献・統計・公的資料にする。個人の体験や印象は根拠にしない。
- 本論の各章の最初の 1 文で、その章の主張を言い切る（段落の頭に結論）。
- 「思う」「感じる」でなく、「〜と考えられる」「〜といえる」を、根拠と組にして使う。
- 字数指定は ±10% 以内に収める。

## 使う部品

`TitleBlock` の簡易ヘッダー（`rp-titleblock--compact`。科目名・学籍番号・氏名を 1 行、その下に表題）、`SectionHeading`、`Callout`（「前提」で議論の範囲を限定する）、`FigureTable`（統計を根拠にするとき）、`References`。要旨は付けない（指定があれば付ける）。

## チェックリスト

- [ ] 課題文の問いに、正面から答えている
- [ ] 序論に問いと結論の予告がある
- [ ] 根拠がすべて出典つきで、個人の感想になっていない
- [ ] 反対の立場を紹介し、それに答えている
- [ ] 序論と結論の主張が一致している
- [ ] 分量の配分（序論 10%・本論 70〜80%・結論 10〜20%）から大きく外れていない
- [ ] 字数の指定を守っている
