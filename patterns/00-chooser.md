# パターンの選び方 / Choosing a pattern

報告の種類は「やったこと」で決める。種類が決まれば、章の名前・必須か任意か・分量の目安が決まる。

## 1. どれを使うか

| やったこと | パターン | 分量の目安 |
| --- | --- | --- |
| 実験・分析・実習をして測定値が出た | A　実験・実習レポート（`01-experiment.md`） | 表紙＋A4 4〜8 枚 |
| 他の研究や資料を集めて整理・比較した | B　文献調査レポート（`02-literature-review.md`） | 授業 2,000〜6,000 字／研究 6〜15 頁 |
| 現地で観測・採取・調査をした | C　フィールド・観測レポート（`03-field-observation.md`） | 巡検 A4 4〜10 枚／研究 8〜20 頁 |
| 既存のデータやモデルを計算・解析した | D　データ解析・シミュレーションレポート（`04-data-analysis.md`） | 授業 A4 4〜10 枚／研究 6〜15 頁 |
| ゼミで進捗や文献の内容を発表する | E　ゼミのレジュメ・進捗報告（`05-progress-report.md`） | A4 1〜2 枚 |
| 研究全体を一本にまとめる | F　卒業研究・論文（`06-thesis.md`） | 学科の規定（30 頁前後〜） |
| 授業の課題に対し、資料を根拠に自分の主張を論じる | G　論述レポート（`07-argumentative.md`） | 2,000〜4,000 字 |
| 授業ごとの短い課題（まとめ・問いへの答え・計算） | H　小レポート（`08-short-report.md`） | 400〜1,600 字 |

分量は、授業で字数・枚数が指定されていればそれに従う。字数指定は ±10% 以内に収める。「○枚」と指定されたときは、指定の書式（多いのは A4・40 字×30 行＝1 頁 1,200 字）で数える。

## 3. 混成ルール

- 主な成果が何かで 1 つ選ぶ。成果が 2 つあるときは、先に出る方をパターンにして、もう一方は章を 1 つ借りる。
- 借りてよい例：C（観測）に D の「付録　再現情報」、A（実験）に B の「文献の整理」（先行研究との比較を厚くしたいとき）、F（論文）は各パターンの章を節として取り込む。
- 借りた章でも、番号・見出しの階層・図表の書き方は選んだパターンのまま。
- 章を削るときは、その章を「必須」としているパターンでは削らない。任意の章は、書くことがなければ作らない（空の章は置かない）。

## 4. 迷ったとき

- 結果の章に「測定値や観察」が入るなら A・C・D、「文献の分類・比較」が入るなら B。
- 「〜について論じなさい」「賛成か反対かを理由とともに述べよ」のように、問いへの自分の答えを求める課題は G。資料をまとめるだけで終わるなら B。
- 「〜について説明しなさい」「〜を要約しなさい」のように説明・要約を求める課題は、G の骨子から「反論への応答」を外して使う。
- ゼミで話しながら配る資料は E（進捗なら E1、文献紹介なら E2）。
- 毎回の授業で出る数百字〜A4 1 枚の課題は H。章立てはしない。
- 提出先が決まった様式（学会・授業の指定）を持つときは、その様式を優先し、足りない部分だけこのパターンで補う。
